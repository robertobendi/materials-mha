A moderation helper for the Materials Cloud Archive

It reads the open submission queue, runs the metadata and file-format checks I use every day, keeps the conversation in view, and drafts a reply from the approved wording. It reads and suggests; the final accept or decline always stays with a human in the Archive itself.

Record checker

Paste a record link, a Materials Cloud ID, or the record JSON and see what the checks find. It runs entirely in your browser, so this one works right here on GitHub Pages. No server, no upload, no login.

Open the checker

Full workspace

The dashboard, conversation history, AI review, and guarded comment sending need the small Python server, because they talk to the Archive with your moderator token. Clone the repository and run it locally.

Setup instructions

This page is static. The checker cannot accept, decline, or comment on anything, and it never sends your data anywhere. The full workspace is read-only by default and can post a comment only after an explicit confirmation; it cannot publish a record.
